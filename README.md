# Анализ резюме HeadHunter

Итоговый проект по Python для анализа данных. В работе выполнены исследование структуры данных, преобразование признаков, разведывательный анализ и очистка данных.

Решение: [Анализ резюме HeadHunter](Анализ_резюме_HeadHunter.ipynb).

Данные:

- [dst-3.0_16_1_hh_database.csv](https://drive.google.com/file/d/158cZ0XKhqfQge8UO4tMLa0dX-BrSDs5I/view?usp=sharing)
- [ExchangeRates.csv](https://drive.google.com/file/d/1qCXsAouTm2JNPmlzBJgGTidTbngiJM2d/view?usp=sharing)

Для запуска файлы CSV должны находиться в одной папке с ноутбуком. Ячейки выполняются последовательно.

Использованы библиотеки pandas, numpy, matplotlib и seaborn.
